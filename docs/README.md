# docs/ — Web Installer

This directory contains a web-based interface that allows you to flash firmware directly from your browser
(Chrome/Edge, via WebSerial) using [ESP Web Tools](https://esphome.github.io/esp-web-tools/)—no need to install PlatformIO.

## Contents
- `index.html` — The flashing page, which includes instructions and security warnings.
- `manifest.json` — A configuration file for ESP Web Tools; it defines the chip family and the
  offset addresses for each firmware component, matching the `partitions.csv` file in the root directory.
- `firmware/` — Contains the actual `.bin` files (bootloader, partition table, boot_app0,
  and the application). **This directory is automatically generated by a GitHub Actions bot; do not edit it manually.**
  See `.github/workflows/build-firmware.yml`.

## What configuration is used for this firmware?
The bot builds the firmware using **default, non-sensitive** environment variables:
`AP_SSID=Free WiFi`, `ADMIN_USER=admin`, `ADMIN_PASS=changeme123`.
Reason: Since these `.bin` files are publicly hosted on GitHub Pages, anyone can download them and
inspect their contents—you should never include actual passwords here.

After flashing via this page, **immediately change** the SSID and admin credentials by visiting
`http://192.168.4.1/admin`. These changes are saved to the device's flash memory and take effect
instantly; no rebuild is required.

If you prefer to build the firmware with your own custom passwords from the start, please use
PlatformIO on your local machine (refer to the main `README.md`) instead of using this public build workflow.
