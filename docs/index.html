🎵 Install Rick Roll Portal firmware

Flash firmware trực tiếp từ trình duyệt qua USB — không cần cài PlatformIO hay VS Code. Firmware được GitHub Actions tự động build mỗi khi có commit mới.

Flash the firmware directly from your browser over USB — no PlatformIO or VS Code setup required. GitHub Actions automatically builds the firmware whenever a new commit is pushed.

Trình duyệt chưa hỗ trợ WebSerial. Hãy dùng Chrome hoặc Edge trên máy tính; không hỗ trợ điện thoại, Firefox hoặc Safari. Your browser does not support WebSerial. Use Chrome or Edge on a desktop computer; phones, Firefox, and Safari are not supported. Trang cần chạy qua HTTPS. GitHub Pages đã tự có HTTPS. This page must be served over HTTPS. GitHub Pages already provides HTTPS.

Cần cáp USB có truyền dữ liệu và trình duyệt Chrome/Edge trên máy tính.

Use a data-capable USB cable and Chrome or Edge on a desktop computer.

Các bước

Installation steps

  1. Cắm ESP32-C3 vào máy tính bằng cáp USB.
  2. Bấm “Kết nối & nạp firmware”, sau đó chọn đúng cổng COM/USB của board.
  3. Chọn “Erase device” khi nạp lần đầu hoặc nếu board từng chạy firmware khác để tránh xung đột dữ liệu NVS cũ.
  4. Đợi khoảng 30–60 giây để nạp xong; board sẽ tự khởi động lại.
  1. Connect your ESP32-C3 to the computer with a USB cable.
  2. Click “Connect & install firmware”, then select the board’s COM/USB port.
  3. Select “Erase device” for a first install or if the board has run different firmware, to avoid conflicts with old NVS data.
  4. Wait about 30–60 seconds for installation to finish; the board will restart automatically.

⚠️ Lưu ý bảo mật

⚠️ Security notice

Firmware công khai được build qua GitHub Actions (xem .github/workflows/build-firmware.yml), vì vậy không chứa tài khoản hoặc mật khẩu admin riêng của bạn. Bản build dùng thông tin mặc định:

The public firmware is built by GitHub Actions (see .github/workflows/build-firmware.yml), so it does not contain your personal admin username or password. The build uses these defaults:

  • SSID mạng giả:Fake Wi-Fi SSID: Free WiFi
  • Tài khoản admin:Admin username: admin
  • Mật khẩu admin:Admin password: changeme123

Việc đầu tiên sau khi flash: kết nối Wi-Fi Free WiFi, mở http://192.168.4.1/admin, đăng nhập bằng thông tin mặc định rồi đổi ngay user/password trong mục “🔒 Tài khoản Admin”. Bạn cũng có thể đổi SSID. Thay đổi được lưu vào flash và áp dụng ngay, không cần nạp lại firmware.

First thing after flashing: connect to Free WiFi, open http://192.168.4.1/admin, sign in with the defaults, then immediately change the username and password under “🔒 Admin Account”. You can also change the SSID. Changes are saved to flash and applied immediately; no reflashing is needed.

Không đưa mật khẩu thật vào biến môi trường của workflow build công khai. Bất kỳ ai tải được firmware.bin đều có thể dùng strings firmware.bin để đọc chuỗi ký tự bên trong.

Never put real passwords in environment variables used by this public build workflow. Anyone who downloads firmware.bin can use strings firmware.bin to read embedded text.

Tự build với mật khẩu riêng

Build locally with your own password

Dùng PlatformIO trên máy bạn thay vì trang này. Xem phần “Cấu hình SSID & tài khoản admin qua biến môi trường” trong README.md ở thư mục gốc repo. Build cục bộ giúp firmware chứa mật khẩu riêng không rời khỏi máy bạn.

Use PlatformIO on your computer instead of this page. See “Configure SSID & admin account via environment variables” in the repository’s root README.md. A local build keeps firmware containing your own password on your computer.
